# Коранът на български

Уеб приложение с арабския текст на Корана и българските му преводи: навигация по сури и аяти, търсене на български и арабски, сравнение на преводите, настройки за четене (размер на шрифта, тъмна тема).

## Публикуване в GitHub Pages

1. Създайте ново хранилище в GitHub (например `quran-bg`).
2. Качете в него **цялото съдържание** на тази папка: `index.html`, `.nojekyll`, `README.md` и папката `data`.
   - През сайта: *Add file → Upload files* и плъзнете файловете и папката `data`.
   - Или от командния ред:
     ```
     git init
     git add .
     git commit -m "Първа версия"
     git branch -M main
     git remote add origin https://github.com/ПОТРЕБИТЕЛ/quran-bg.git
     git push -u origin main
     ```
3. В хранилището отворете *Settings → Pages*. При *Source* изберете *Deploy from a branch*, клон `main`, папка `/ (root)` и натиснете *Save*.
4. След 1–2 минути сайтът е на адрес `https://ПОТРЕБИТЕЛ.github.io/quran-bg/`.

Приложението зарежда файловете от `data/` с `fetch`, затова не работи, ако отворите `index.html` направо от диска. За локален преглед пуснете в папката `python3 -m http.server` и отворете `http://localhost:8000`.

## Връзки към аяти

`…/#s2` отваря сура 2, а `…/#s2-255` отваря аят 2:255.

## Данни

| Файл | Съдържание |
|---|---|
| `data/ar.json` | Арабски текст, Tanzil Quran Text (Simple), CC BY 3.0, tanzil.net |
| `data/bg-theophanov.json` | Превод на Цветан Теофанов (по Tanzil.net) |
| `data/bg-dobrev.json` | Превод на проф. д-р Иван Добрев, разпознат (OCR) от сканираното издание. Не е напълно проверен |
| `data/bg-dobrev-flags.json` | Аяти от превода на Добрев, отбелязани „за проверка“ |
| `data/bg-gendzhev.json` | „Свещен Коран и неговият превод на български език“, ръководител Недим Генджев, разпознат (OCR) от сканираното издание. Не е напълно проверен. Аяти 2:260–264 липсват в сканираното копие |
| `data/bg-gendzhev-flags.json` | Аяти от превода на Генджев, отбелязани „за проверка“ |
| `data/bg-hayraddin.json` | „Прещедрият Коран“, превод на Али Хайраддин |
| `data/meta.json` | Арабски имена на сурите, брой аяти, Мека/Медина, джузове, сажди |

Всеки файл с превод е масив от 114 масива (по един за сура), всеки с текста на аятите поред, общо 6236.

## Добавяне на превод

1. Добавете файл `data/bg-<име>.json` в горния формат.
2. В `index.html` добавете запис в масива `TRANSLATIONS`:
   ```js
   { id: "ime", name: "Име на преводача", file: "data/bg-ime.json", note: "Кратко описание и източник." }
   ```

За да махнете превод, изтрийте неговия запис от `TRANSLATIONS`.

## Авторски права

Преводите на български са защитени с авторско право. Преди да публикувате публично, уверете се, че имате разрешение за всеки превод, особено за преводите на проф. Добрев, на колектива с ръководител Недим Генджев и на Али Хайраддин. GitHub Pages е публичен, дори ако хранилището е частно (освен при платените планове на организация).
